# Odin Recipes — Resident Evil Edition

A themed adaptation of the Odin Recipes project from [The Odin Project](https://www.theodinproject.com/).

## About the Project

Odin Recipes is a beginner HTML project focused on building a simple website with multiple pages.

For this adaptation, the traditional recipe theme is replaced with the **Resident Evil video game franchise**. Each page will represent a different installment of the saga, featuring information and visual content related to each game.

## Learning Objectives

Through this project, I will practice and demonstrate the following HTML fundamentals:

- Creating HTML boilerplate and document structure.
- Using headings and paragraphs.
- Adding images with appropriate attributes.
- Creating links between pages using relative paths.
- Organizing content with ordered and unordered lists.
- Structuring a multi-page website.
